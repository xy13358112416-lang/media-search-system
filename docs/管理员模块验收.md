# 在线管理员模块验收

负责人为陈智敏。代码基线为 3d2e925，验收日期为 2026 年 11 月 22 日。

## 自动验收

新增 admin_integration 启动真实服务器，使用临时 SQLite 和两条以上 TCP 连接验证以下场景。

- 旧结构数据库启动时自动创建附加权限表，旧账号默认是普通用户。
- --add-admin 创建的账号登录返回管理员身份。
- 普通用户直接调用管理接口被拒绝，伪造 is_admin 字段不能提权。
- 管理员创建普通账号，重复用户名被拒绝。
- 用户列表分页上限为 100，非法分页参数被拒绝。
- 停用普通用户后当前连接断开，新登录被拒绝，启用后可登录。
- 重置密码后当前连接断开，旧密码失败，新密码成功。
- 管理员不能通过这些接口停用自己或管理其他管理员。
- 人工制造审计写入失败时，密码修改回滚，旧密码继续有效。
- 管理员可维护他人公开仓库，普通用户对此只读，管理员访问他人私有仓库被拒绝。
- 普通用户原有本人私有仓库新增继续成功。
- 重启服务器后角色、密码及数据仍可读取，SQLite 完整性检查通过。

运行单项检查的方法如下。

```powershell
ctest --test-dir build -R admin_integration --output-on-failure
```

完整回归结果在本文件末尾记录。

## 界面人工验收

1. 启动服务端，确认客户端先显示用户登录和管理员登录两个选项；选择用户登录后，用旧普通账号登录，检查原媒体库、检索、仓库、足迹和推荐入口及布局。
2. 从服务端控制台创建管理员，选择“管理员登录”进入对应窗口，登录后确认顶部出现“管理”。
3. 打开管理窗口，刷新、切页、创建账号，验证空页和错误提示，关闭窗口后返回原页面。
4. 用另一客户端登录新建普通账号，管理员停用该账号，观察其返回登录窗口，启用后重新登录。
5. 管理员重置普通账号密码，验证旧密码失败、新密码成功。故意输入短密码，确认错误提示且数据未变。
6. 管理员打开他人公开仓库，新增并删除一条测试媒体；另一客户端刷新媒体库和检索页，核对新增可查、删除后消失。
7. 普通账号操作他人公开仓库，确认新增删除按钮不可用。切到本人仓库，确认原有操作可用。
8. 打开管理弹窗时断开服务器，确认弹窗关闭、回到登录。切换账号后确认普通账号没有管理按钮。
9. 检查高 DPI 与小屏幕下管理窗口的表头和按钮。管理员页面沿用当前浅色样式。

## 双端联调与资料

实际两台电脑使用同一批次构建的客户端和服务器，服务端指定原数据库、端口和局域网地址。服务器环境变量继续使用 MEDIA_SERVER_DEEPSEEK_API_KEY。管理员模块不向客户端传递模型密钥。记录客户端电脑、服务器电脑、构建 commit、数据库路径和实测时间。

自动回归不能替代两台实体电脑的界面验收和真实 DeepSeek 调用。当前交付范围是账户管理及公开媒体维护，管理员账号的远程密码维护、角色转换、账号物理删除和内容编辑尚无独立页面。

2026 年 11 月 22 日使用 Windows x64、Qt 6.11.2、MinGW 13.1、Release 构建，源码为 media-search-frontend，构建目录为 build/admin-module。

- warehouse_page_tests 通过，其中新增真实 OnlineCareClient 登录并打开管理弹窗，自动确认两行用户以及管理员角色显示。
- 原有 47 个测试条目全部通过，包含媒体检索、仓库权限、历史足迹、人物、推荐与取消、登录及前端回归。
- Qt 界面自动测试使用 offscreen。双实体电脑、高 DPI 人工操作和真实模型网络调用尚待按照前文清单验收。

管理员模块当前已在源码和本机构建完成。原有已分发的 ZIP 需要重新构建发布后才包含管理入口。

## 双入口补充验收

- 选择页面在提交身份前不连接服务器，关闭选择窗口可退出。
- 用户与管理员入口分别显示用户登录和管理员登录标题，正确传递角色。
- 普通账号选管理员入口、管理员账号选用户入口均被服务端拒绝，失败后仍未认证，同连接可用正确入口角色重试。
- login_role 非法类型被拒绝，省略该字段的旧登录请求继续按账号真实身份处理。
- 在途登录时点击返回选择，再选择另一个身份，原登录迟到结果不进入新会话。
- 客户端换号或断线后重新进入身份选择。

双入口版本全量回归同样为 48/48 通过，包含实际选择用户与管理员登录、返回选择后丢弃迟到登录回复、真实 TCP 角色校验和旧登录兼容检查。
