# 测试样例说明

`data/media_records.csv` 是 30 条完全虚构的联调数据，作品、人名、奖项、日期、扩展名、文件大小和浏览次数均为测试生成值，不代表真实作品、真实媒体文件或统计结果。`file_size` 的单位为字节，文件本身并不存在，不应把样例当作实际采集数据或真实性能结论。

列顺序与当前 `DATA_INTERFACES.md` 一致；UTF-8 编码，首行为字段名。`actors` 和 `awards` 暂定为 JSON 字符串数组，空列表写 `[]`。先用标准 CSV 解析器取出字段，再用 JSON 数组解析器取回完整字符串列表；写入时顺序相反。CSV 必须正确处理引号、逗号和换行，不可直接按逗号切分。此约定供组员联调，尚未实现项目中的 CSV 读取器，也没有通过组员确认。

所有 ID 在本样例中固定且唯一；同名作品有不同 ID。数据有重复导演、演员和类型的交叉组合；例如导演 `林川`、演员 `陈明`、类型 `MP4` 同时满足时应命中 `M000001` 和 `M000002`。

可在本目录运行 `python generate_sample.py` 重新生成相同文件；再运行 `python -m unittest discover -s tests -v` 检查格式、唯一性、日期、列表和组合条件。生成脚本会覆盖本目录下的样例文件，不要用于保存正式数据的目录。
